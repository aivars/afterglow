# Contributing

- Run the tests with `swift test` before opening a PR.
- Translations live in `Sources/Afterglow/Resources/Localizable.xcstrings`. Add or fix strings there; the chrome strings are localized in en, de, es, fr, ko, zh-Hant.
- Keep the rules in "Rules baked in" in the README intact. PRs that weaken them (for example requesting the system rating prompt from a button tap, or showing the sheet on a fresh install) will not be merged.
